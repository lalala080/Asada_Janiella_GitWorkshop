# Asada_Janiella_GitWorkshop

This project is a simple webpage about a game. It includes information about the game, featured characters, game features, and game ratings.

The webpage was created using HTML and CSS and was developed through three different versions using Git.

## Versions

### Version 1
Created the basic structure of the webpage using HTML.

### Version 2
Added CSS styling and improved the appearance of the webpage.

### Version 3
Added game features and game ratings and made further improvements to the webpage.

## Technologies Used

- HTML
- CSS
- Git
- GitHub

## Git Commands Used

- `git init`
- `git status`
- `git add`
- `git commit`
- `git log`
- `git branch`
- `git remote`
- `git push`
